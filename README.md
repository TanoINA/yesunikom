# YES UNIKOM

Youth English Society (YES) adalah UKM bahasa Inggris di Universitas Komputer Indonesia, Bandung. Di YES, mahasiswa bisa berlatih bahasa Inggris lewat diskusi, public speaking, dan kegiatan bersama.

[Buka situs YES](https://tanoina.github.io/yesunikom/)
